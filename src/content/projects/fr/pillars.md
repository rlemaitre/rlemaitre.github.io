---
summary: Une bibliothèque Scala 3 pour construire des applications backend, avec des outils pour développer, tester et documenter des endpoints REST.
---

Avec Pillars, vous définissez des routes, traitez des requêtes et générez la documentation de l’API avec un minimum de code répétitif.
Que vous construisiez une nouvelle API de zéro ou que vous ajoutiez des fonctionnalités à une API existante, Pillars vous laisse vous concentrer sur votre logique métier plutôt que sur l’infrastructure.
